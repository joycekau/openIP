Performance metrics

Two scorecards, one bridge

The Academy and the Tools are two different businesses. Keep their scorecards separate — then watch the bridge that connects them, because that's where the strategy lives or dies.

★ North-star metric

Graduates monetizing — students earning income with AI (e.g. ≥ RM500/mo)

It proves the Academy (marketing), drives Tools retention (they keep using Cora/OneIP to earn), and justifies premium pricing — all at once. Financial twin: blended MRR (amortized course revenue + tool subscriptions).

Build sequence

Do these in order

  1. Ship Rung 1 first. The 2-hr intro is the engine's ignition — build and sell it before anything downstream, and script it to end with the Bootcamp offer.
  2. Lay the money + delivery rails: payment with installments, LMS/webinar, CRM, and automated tool provisioning (enrol → Cora AI Gateway / OneIP account + bundled credits). Attach rate depends on this.
  3. Build the Bootcamp (Rung 2) while intro cohorts run — that's where revenue and tool-attach concentrate.
  4. Outline rungs 3–5 and open a waitlist / deposit before building them fully. Let demand fund the build.

The intro-course launch play (Rung 1)

The content is a demo of the ladder — teach, then sell the next rung live:

  1. Teach the OPC concept → demo Cora AI Gateway live (Chat / Cowork / Video Studio) → show an OneIP monetization example.
  2. Present the 3 monetization paths.
  3. Make the Bootcamp offer with an on-the-spot upgrade credit (the RM299 counts toward it).
  4. Drive the close with hard scarcity: RM999 list, RM299 for the first 20 seats only — show an "X of 20 left" counter; later cohorts get a smaller discount, never back to RM299.
  5. Run it weekly as a repeatable cohort — each intro is both revenue and top-of-funnel.
